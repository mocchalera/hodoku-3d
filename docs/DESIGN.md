# 時間を繕うゲーム — 3D版

この文書のゲームコンセプトを維持したまま、3D版では「図版」を「回り込める街の模型」に発展させました。視点・立体化・実装のCurrent Truthは `3D_ARCHITECTURE.md` を参照してください。

## 核

「もっと道路をつくる」ではなく、「今ある街の時間を取り戻す」。
プレイヤーは市長や全能の都市開発者ではなく、街の朝を少し預かる修繕係。1本の道を増やすことと、信号の数秒を変えることを同じ設計机に置く。

## 抽象化

路線図の考え方にならい、現実の縮小コピーよりも接続・順序・待ち合わせを読みやすくした。山、川、鉄道、家々は土地の気配を残すが、実在の位置を示さない。操作する対象は5つの結び目に絞った。

少手数パズルから、操作の速さではなく一手の意味を考える制限を借りた。3手は試行回数ではなく、1つの完成案に含める介入数。何度でも書き直せるので、失敗は取り返せない損失にならない。

版画の限られた色数と図版の余白を手がかりに、地図の記号を絞った。紙の生成り、道路の墨緑、混雑表示の朱、バスの真鍮色。車体は個体ごとの固定色とし、停止で塗り替えない。装飾的な発光・カードの山・数値の常時点滅を主役にしない。

## 三つの異なる問題

第1景：右折待ちが直進を止める。曲がるための空間と、下流の信号の時刻を組み合わせて小さな予算で解く。

第2景：いくつかの車線は改良済みだが、駅へ向かう脇道と横断の時間配分が偏っている。高架と信号変更でも勝てる一方、より少ない予算の工夫も有効。

第3景：車線整備は終わり、道路を買い足す同じ解は使えない。青の長さと時刻の組み合わせを探す。車だけを助けて横断を長く待たせないようにする。

## 反実仮想の公正さ

原案と変更案に別の交通を流すと、改善が設計によるものか偶然か区別できない。そこで需要をすべて先に生成し、同じ出発時刻・経路・人数で比較する。点数を対策カードへ直接加算しない。

地図の入口が詰まると、入れなかった車も列と待ち時間の帳簿に残す。見えていない人を消して勝たせない。

## 音

音は初期OFF。ONにしたときだけ、街を抜けた車が控えめな音をつくる。音量を競わせず、流れが戻ることに小さな手触りを添える。ブラウザのWeb Audioで生成し、外部音源を使わない。

## 意図的に入れなかったもの

CO₂や安全性の精密な点数、住民満足度の架空メーター、用地取得の現実価格、現地の渋滞改善保証。今回のモデルで根拠を持てない数値を、もっともらしい評価項目として増やさない。

オンラインランキング、リアルタイム交通API、全国自動生成も本版の範囲外。最初の目的は、公開値から始まる小さな交通パズルを実際に遊べること。
