# 観測値とモデルの境界

## 原典

長野県公開「令和3年度 全国道路・街路交通情勢調査 一般交通量調査」。2024年9月訂正版。2026-09-08確認。

時間帯別交通量表9ページの観測地点11090 / 11100 / 11110を、箇所別基本表3ページと地点番号で結び、宮田・鎌田・渚であることを確認した。表中の数字を読み、PDFのページ画像でも該当行を確認。OCRは使用していない。

原表の時間列は7時台から始まり、6時台までの24列。`src/data.js` と `data/traffic-observations.json` では小型・大型、上り・下りを分離して保存している。

実際に使うセルはREADMEの表のとおり。`observed(stage)` は時間列を `(hour - 7 + 24) % 24` で選び、小型＋大型を合計する。

## 観測値から需要へ

幹線入口ごとの生成数は概ね `round(方向別台数/時 × 負荷係数 × 1200/3600 ÷ 2)`。負荷係数は第1景1.03、第2景1.20、第3景1.04。これは難易度用の創作パラメータで、観測補正や現況推定ではない。

幹線の向きと上下方向の対応も架空の街への割当。地理的な南北の実測値と呼ばない。

脇道には方向平均に各交差点の創作した比率を乗じた流入がある。バス割合4.5%、バス1台14人・一般車1台1.25人という人数換算、歩行者数、分岐率、速度もゲーム設定。バス率は大型車率から導いていない。

1車両エージェントは2台相当。1歩行者点は2人相当。これは描画とゲーム規模のためのサンプリングで、現実の飽和交通流率の校正ではない。

## 車の動き

固定刻み0.5秒。各方向のリンクに有限の空間と車列を持つ。前車の位置、信号、次リンク入口の空き、発進間隔から進める距離を決定する。次リンクに車体全体が横断歩道を抜けて収まる空間がなければ、交差点への進入を止める。停止線は描画と共通の位置を使い、車体の先端と余白を含めて停止位置を決める。青で進入済みの車にはクリアを認め、赤で未進入の車は停止線の手前で待つ。

右折レーンがなければ曲がり待ちと直進が同じ車列になり、あれば別の車列になる。2.1では経路の向きから右折と左折を区別し、右折待ちのみ右折レーンへ分ける。対向流の先頭車と交差点内の車を使う簡易的な通過可否判定を行い、右折矢印では対向直進を止める。実測に校正されたギャップアクセプタンスや全車両の連続的な衝突物理ではない。

高架は幹線の直進車にだけ信号回避を許す。分岐車、下流容量、車間距離の制約は残る。対策の効果はこのモデルから生じ、工事ごとの固定ボーナスで加算しない。

信号1周期の基本枠は90秒。主道枠は24–64秒で、通常はこれが主道青になる。別に黄色・切替の合計8秒を設け、残りを脇道に割り当てる。右折専用信号を付けた場合は主道枠の最後の12秒を切替4秒＋右折矢印8秒へ振り分ける。主道直進・脇道・右折矢印は排他的で、既に進入した車や歩行者が残る場合は競合する青を保留する。

歩行者は脇道青の一部で横断開始する。接近1秒＋横断6秒を見込み、青の終了前に新規横断を締め切る。横断完了は歩道へ到達した時点で計上し、同じ描画エージェントがさらに歩道を14秒歩いてから消える。歩道の待機列・退出経路は道路幅と向きから生成する。交差点内の全ての二次元接触や、現実の歩行速度・安全設計基準によるクリアランスはモデル化していない。

## 比較と指標

全到着予定はシミュレーション前に生成。原案と変更案で完全に共有し、同じ固定時間刻みで1200秒評価する。

車の待ち時間は各刻みの「自由走行時に進める時間 − 実際に進んだ距離/自由速度」。その場で止まった時間に加え、追従などで遅くなった分も含む。人数換算で積算し、歩行者の信号待ちを加えた人・分を目的量にする。

未入場車は待機リストに残して待ち時間を積算。評価期間末の未到着車もそれまでの遅れを含む。ただし、1200秒後に全員が到着するまでの遅れは外挿しない。完了台数の条件も設けて入口抑制による有利さを制限する。

車・歩行者数の保存、同一需要、同じ設計の再実行の一致、車線内の前後間隔、数値の有限性をテストしている。現実の交通を予測できることの検証ではない。

## 評価していないもの

事故、歩行者との二次元の接触、安全設計基準、排出量、燃費、用地、騒音、工期、迂回、経路選択の変化、誘発需要、季節変化、現在の実交通、災害対応。

実務用の交通シミュレータではなく、公開値からつくったフィクションのゲームとして扱うこと。
